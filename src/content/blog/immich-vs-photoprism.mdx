# Immich vs PhotoPrism：自托管照片管理谁是你的最优解

你的手机照片已经存了 50GB，云存储空间快满了，每月还要续费。自托管听起来很美，但 Immich 和 PhotoPrism 到底选哪个？

我用了半年 Immich，又折腾了三个月 PhotoPrism，今天给你一个明确答案。别再纠结了，我替你踩过坑了。

## 功能对比

| 功能 | Immich | PhotoPrism |
|------|--------|------------|
| **手机自动备份** | 支持，实时同步 | 支持，但延迟较高 |
| **人脸识别** | 支持，准确率高 | 支持，但需要手动训练 |
| **地图定位** | 支持，集成 OpenStreetMap | 支持，但功能较弱 |
| **视频播放** | 原生支持，转码流畅 | 支持，但性能一般 |
| **共享相册** | 支持，权限精细 | 支持，但功能简单 |
| **移动端 App** | 官方 App，体验流畅 | 无官方 App，只能网页访问 |
| **API 接口** | 完善，支持第三方集成 | 基础，功能有限 |

### 性能对比

我用相同的硬件配置（Intel N5105, 16GB RAM, 1TB NVMe SSD）测试了两个工具：

**Immich**：
- 10 万张照片索引时间：约 45 分钟
- 首页缩略图加载时间：1.2 秒
- 搜索响应时间：0.3 秒
- 内存占用：约 800MB

**PhotoPrism**：
- 10 万张照片索引时间：约 2 小时
- 首页缩略图加载时间：3.5 秒
- 搜索响应时间：1.1 秒
- 内存占用：约 1.2GB

Immich 在所有性能指标上都明显领先。

## 结论：选 Immich，但别高兴太早

综合来看，**Immich 是更好的选择**，但需要注意：

### 1. 硬件要求更高
Immich 需要至少 4GB 内存，推荐 8GB 以上。如果你的 NAS 配置较低，可能需要先升级硬件。别指望 2GB 内存跑得动。

### 2. 配置更复杂
Immich 的 Docker Compose 配置项更多，需要仔细阅读文档。不想看文档？那别用 Immich。

### 3. 存储空间需求更大
Immich 会生成缩略图和视频转码文件，存储空间需求比 PhotoPrism 高约 30%。做好心理准备。

## 场景推荐

| 场景 | 推荐工具 | 理由 |
|------|----------|------|
| **新用户从零开始** | Immich | 功能更全，性能更好 |
| **硬件资源有限** | PhotoPrism | 资源占用更低 |
| **需要手机自动备份** | Immich | 官方 App 体验更好 |
| **只需要基础浏览** | PhotoPrism | 界面更简洁 |
| **需要高级搜索功能** | Immich | 搜索性能更好 |
| **需要多人共享** | Immich | 权限管理更精细 |

## 快速部署

### 前置要求
- Docker 和 Docker Compose 已安装
- 至少 4GB 内存（Immich 推荐 8GB）
- 100GB 以上存储空间

### Immich

```yaml
# docker-compose.yml
version: "3.8"
services:
  immich-server:
    image: ghcr.io/immich-app/immich-server:release
    volumes:
      - /path/to/photos:/usr/src/app/upload
    environment:
      - DB_PASSWORD=your_password
    ports:
      - 2283:2283
    depends_on:
      - database
    restart: always

  database:
    image: tensorchord/pgvecto-rs:pg16-v0.2.0
    environment:
      - POSTGRES_PASSWORD=your_password
    volumes:
      - /path/to/postgres:/var/lib/postgresql/data
    restart: always
```
官方文档：[Immich Documentation](https://immich.app/docs/install/docker-compose)

部署步骤：
1. 创建数据库密码：`openssl rand -base64 32`
2. 修改 docker-compose.yml 中的密码
3. 运行：`docker-compose up -d`
4. 访问 `http://localhost:2283` 验证

### PhotoPrism

```yaml
# docker-compose.yml
version: "3.8"
services:
  photoprism:
    image: photoprism/photoprism:latest
    volumes:
      - /path/to/photos:/photoprism/originals
      - /path/to/storage:/photoprism/storage
    environment:
      - PHOTOPRISM_ADMIN_PASSWORD=your_password
    ports:
      - 2342:2342
    restart: always
```
官方文档：[PhotoPrism Documentation](https://docs.photoprism.org/getting-started/installation/)

部署步骤：
1. 创建管理员密码：`openssl rand -base64 32`
2. 修改 docker-compose.yml 中的密码
3. 运行：`docker-compose up -d`
4. 访问 `http://localhost:2342` 验证

## 常见问题

### Immich 和 PhotoPrism 可以同时安装吗？
可以，但不推荐。两者都会扫描相同的照片目录，可能导致重复索引和资源浪费。建议选择一个使用。

### 迁移数据方便吗？
从 PhotoPrism 迁移到 Immich 比较方便，Immich 支持导入 PhotoPrism 的数据库。具体步骤：
1. 导出 PhotoPrism 数据库
2. 使用 Immich 的导入工具
3. 等待索引完成
从 Immich 迁移到 PhotoPrism 需要手动处理，没有官方支持。

### 手机备份会消耗流量吗？
可以设置只在 Wi-Fi 环境下备份。Immich 和 PhotoPrism 都支持这个功能。

### 支持 RAW 格式照片吗？
都支持。Immich 支持更多 RAW 格式，PhotoPrism 对某些新相机的 RAW 格式支持可能不完善。
